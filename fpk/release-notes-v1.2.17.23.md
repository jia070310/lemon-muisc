# 柠檬音乐 v1.2.17.23

## 更新内容

### 页面打开加速（本地缓存）

- 发现 / 音乐库 / 播客首屏数据写入本地缓存，再次打开先秒开再静默刷新
- 发现页歌单按屏渐进加载：静置最多预取到第 3 屏，滑到第 2 屏再拉第 4 屏
- 音乐库浏览预览（歌手/专辑/流派/歌单卡）与播客列表支持过期后后台替换，减少弱设备卡顿

### 投屏连播

- 修复小米电视投屏播完一首后不按播放模式继续的问题
- 切歌不再继承上一首偏长时长，避免永远等不到下一首
- 短曲忽略误报 STOPPED 的窗口按曲长缩短；前端在服务端持有队列时不再本机重推打断切歌

### 其他

- 网易云封面、酷狗歌单解析与投屏窗口体验延续上一版优化

## 安装 / 更新

- x86：`lemon-music-1.2.17.23-x86.fpk`
- ARM：`lemon-music-1.2.17.23-arm.fpk`
