# 柠檬音乐 v1.2.16.18

自 **v1.2.16.17** 以来的修改与修复。

## 更新内容

### 导航 / 切换栏目

- **修复骨架卡住**：手机端（飞牛 WebView）从音乐库切到搜索等栏目时，有时一直停在「框架刷新」动画、真实页面刷不出来；切走再回来又正常。根因是触控预加载过早打开骨架并隐藏页面，导航未真正完成时无法关闭
- 预加载只拉页面代码，骨架仅在真正路由跳转时出现；超时自动关闭；骨架改为遮罩，不再把已缓存页面藏起来

### 音乐库角标

- 进入歌手 / 专辑 / 风格等详情时，角标跟随当前栏目曲目数
- 回到音乐库首页后恢复全库总数

### 整理标签（手机）

- 过滤框与工具栏排版调整，过滤更明显、信息更紧凑

### 关于页 · FPK 加速保存

- 多镜像轮询下载；已去掉易超时的 `gh-proxy.com`

### 图标

- 飞牛应用中心 / PWA：橙底方标
- 网页 favicon：透明底

## 安装 / 更新

- x86：`lemon-music-1.2.16.18-x86.fpk`
- ARM：`lemon-music-1.2.16.18-arm.fpk`
