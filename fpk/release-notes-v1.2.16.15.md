# 柠檬音乐 v1.2.16.15

自 **v1.2.16.14** 以来的修改与修复。

## 更新内容

### 音源平台

- **按音源单独开关平台**：每个音源可单独选择解析哪些平台（仅对本账号生效）
- **试听过多自动关闭解析**：若某平台近期多为试听片段，会自动关闭该音源对它的解析，减少无效取链
- **平台开关改为悬浮窗口**：点击「平台」弹出独立卡片配置，不再撑开音源列表行

### 播放 / 歌词

- **修复逐字歌词**：全屏「逐字」按官方字级时间轴扫光（KRC / YRC），不再把整句均分成模拟进度；网易绝对毫秒与酷狗相对行首均可识别

### 其他

- 忘记密码说明补充
- FPK 打包时一并打入 OpenAPI 规格文件

## 安装 / 更新

- x86：`lemon-music-1.2.16.15-x86.fpk`
- ARM：`lemon-music-1.2.16.15-arm.fpk`
