# 柠檬音乐 v1.2.16.19

自 **v1.2.16.18** 以来的修改与修复。

## 更新内容

### 音源导入 / 激活

- **修复导入后假死**：列表接口不再每次把全部音源脚本读进内存重解析；大脚本导入后刷新列表不易卡住整站
- **在线导入更快**：GitHub 多镜像改为竞速，避免串行各自卡满超时
- **激活 / 停用忙态**：按钮显示「激活中… / 停用中…」，避免连点后像卡死
- **沙箱定时器清理**：激活失败或卸载时清理脚本里的 `setTimeout` / `setInterval`，降低后台拖死事件循环的风险
- 导入成功提示：需再点「激活」后才能搜索 / 播放

## 安装 / 更新

- x86：`lemon-music-1.2.16.19-x86.fpk`
- ARM：`lemon-music-1.2.16.19-arm.fpk`
