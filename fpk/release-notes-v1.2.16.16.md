# 柠檬音乐 v1.2.16.16

自 **v1.2.16.15** 以来的修改与修复。

## 更新内容

### 收藏 / 歌单

- **收藏专辑与歌手**：收藏页为歌曲 / 专辑 / 歌手三栏
- **歌单去重**：同名单曲可按规则保留一首，减少重复曲目

### 歌词 / 播放

- **全屏改歌词**：可从网络挑选歌词（QQ / 网易云）；本地曲目可写入文件并锁定，避免之后被短歌词覆盖；同时写入 `.lrc` 旁路
- **修复逐字歌词**：切歌后扫光不再卡住

### 标签编辑

- **网络获取弹窗重排**：固定高度、左右分栏（列表 + 预览）、页脚始终可见；弹窗内 QQ / 网易云切换按钮

## 安装 / 更新

- x86：`lemon-music-1.2.16.16-x86.fpk`
- ARM：`lemon-music-1.2.16.16-arm.fpk`
