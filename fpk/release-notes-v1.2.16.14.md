# 柠檬音乐 v1.2.16.14

## 更新内容

### 音乐库

- **每日推荐**：按收藏 / 最近播放生成本地 Daily Mix，夜间时段 22:00 后解锁
- **推荐歌单**：华语热歌榜、车载慢摇从网络歌单抽取，一天一换
- 所有歌手、所有风格入口；扫描时曲目数实时更新

### 导航与发现

- 左侧栏可折叠；搜索回到主导航；打开应用默认进入音乐库
- 发现页歌单默认按最新排序；搜索空态卡片与音乐库风格对齐

### 情绪地图

- 地图 / 概览双模式；手机端顶栏避让与图标样式调整

### 设置与安装

- 设置分类整理（账号 / 试听下载 / 风格样式等）；取消邮件服务
- 安装后默认管理员，首次登录即提示改密；保证至少一名管理员
- 安装默认端口 **7983**，向导不再填端口；被占用到应用设置修改后停用再启用
- 忘记管理员密码只改登录，不清歌单和音乐文件（关于页有命令）

### 下载与播放

- 循序下载可暂停 / 继续；全屏歌词体验打磨
- 去重列表显示文件大小
- 音源取链兼容落雪 callback；超时取消请求；429 拉长重试；单曲失败不停用整个音源

### 开放 API / 飞牛

- `/api/docs` 随包装入 OpenAPI 规格，Swagger 可列出接口
- 修复飞牛桌面图标 /「打开」无反应（空端口未写入桌面地址）
