# 柠檬音乐 v1.2.16.10

## 更新内容

### 路径权限（多用户）

- 管理员可为账号指定路径策略：**使用管理员路径** / **使用专属路径** / **允许用户自行选择**
- 覆盖**音乐库目录**与**下载目录**；专属模式下用户可配置自己的音乐库与下载路径
- 音乐库曲目 / 歌手 / 专辑 / 风格、情绪地图、文件管理均按当前用户生效路径过滤

### 歌单下载

- **循序 / 分批下载**：可设批次大小与间隔，减轻连续拉歌压力
- 可选按歌单名称创建保存子文件夹

### 车机 / 弱网流畅播放

- 本地无损转 AAC 码率调整为约 **128kbps**；播放时预热下一首
- 开启流畅播放时自动关闭音频可视化（Web Audio 在 CarPlay 上易卡）
- 降低锁屏 / 车机 Now Playing 进度推送频率，减轻跨进程通信卡顿
- 流畅模式下在线试听音质也会压到 128k

## 安装 / 更新

- x86：`lemon-music-1.2.16.10-x86.fpk`
- ARM：`lemon-music-1.2.16.10-arm.fpk`
