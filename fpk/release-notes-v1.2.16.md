# 柠檬音乐 v1.2.16

## 更新

### 全屏歌词

- 支持逐行 / 逐字；酷狗 KRC 真逐字高亮
- 滚动后空闲自动回当前行；工具栏随界面显隐

### 关于页

- 更新说明、镜像加速、x86 / ARM 安装包直链（请按 NAS 架构手动选择）

### 标签与下载

- 匹配参考文件夹、仅补全缺失；按字段批量写入；合唱曲多歌手可见
- 同名不同格式下载并存；设置侧栏固定与独立标签管理页

本版仍为原生独立应用（不依赖 Docker），依赖应用中心 Node.js v22。

## 安装包

- x86：`lemon-music-1.2.16-x86.fpk`
- ARM：`lemon-music-1.2.16-arm.fpk`
