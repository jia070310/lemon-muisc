# 柠檬音乐 v1.2.16.11

## 更新内容

### 关于页：FPK 保存到 NAS

- 管理员可将安装包经 **加速** / **直连** 拉到 NAS「下载目录/柠檬音乐更新」
- 显示下载进度、成功与失败提示
- 同名文件自动按 `-1` / `-2` / `-3`… 递增，不覆盖已有包

### 歌单批量下载

- 「批量下载确认」亦可勾选 **保存到歌单文件夹**（与整单循序下载一致）
- 开启后文件写入下载目录下以歌单名命名的子文件夹

## 安装 / 更新

- x86：`lemon-music-1.2.16.11-x86.fpk`
- ARM：`lemon-music-1.2.16.11-arm.fpk`
