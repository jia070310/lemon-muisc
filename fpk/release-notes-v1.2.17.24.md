# 柠檬音乐 v1.2.17.24

## 更新内容

### 大曲库性能
- 扫库上限由 5 万提升至 30 万，避免大库入库被截断
- 设置页目录树改为懒加载：初始不展开、不预取全部子目录（上万一级目录时不再打爆 NAS）
- SQLite 页缓存 / WAL checkpoint / mmap 等 PRAGMA 调优
- 内存软硬限默认 1536 / 2048MB，减少大库误清缓存
- 情绪标定百分位改二分查找；自动补跑每轮 300 首 + 8 分钟冷却（手动仍全量）
- discover-warm 拉长间隔 + 失败源冷却；启动后台任务错峰

### 播放体验
- 外网播放 NAS 本地文件：有 metadata 即开播，缩短相对在线平台的多余等待
- 仅弱网保留短缓冲等待；局域网与普通外网不再人为拖延
- 手机端禁用 Web Audio 直通（含频谱），切后台彻底 `close` AudioContext，减轻无线 CarPlay 断续
- 桌面端仍保留频谱直通

### 下载 · 歌词
- 新增「歌词样式」：逐行（默认）/ 逐词；内嵌与下载 `.lrc` 共用
- 逐词会拉取增强时间轴并写入增强 LRC，无逐词数据时回退逐行

### 关于页 · QQ 群
- 群号与二维码每天从 GitHub README 经加速节点拉取并落盘缓存
- 删除缓存后强制刷新，避免旧二维码残留；安装包不再打入整夹截图

### 音源设置
- 监测自动关闭平台后，下拉开关与提示状态同步
- 音源卡片桌面 / 手机排版对齐
