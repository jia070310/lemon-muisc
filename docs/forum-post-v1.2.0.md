# 【更新】柠檬音乐 v1.2.0：独立原生应用，不再依赖 Docker

项目地址：  
[https://github.com/jia070310/lemon-muisc](https://github.com/jia070310/lemon-muisc)

发布页：  
[https://github.com/jia070310/lemon-muisc/releases/tag/v1.2.0](https://github.com/jia070310/lemon-muisc/releases/tag/v1.2.0)

这是一次面向飞牛应用商店的架构重写版本。应用中心显示名为 **柠檬音乐**，浏览器打开后标题仍为「柠檬音乐下载」。

## 为什么重写

旧版以 Docker 容器运行。飞牛重启时，若 Docker 尚未就绪，应用自动启用容易失败，并出现「docker服务不可用」。  
v1.2.0 改为飞牛**原生独立进程**，不再拉镜像、不依赖 Docker。安装包约 0.5 MB，运行时使用应用中心官方依赖 **Node.js v22**（未安装时会随本应用一并安装）。开机与启用更直接、更稳。

## 应用功能

柠檬音乐是面向飞牛 NAS 的 Web 音乐工具，兼容落雪音乐自定义音源脚本，可在浏览器中完成「找歌 → 试听 → 下载 → 整理」。

### 搜索与发现

- 支持酷我、酷狗、QQ 音乐、网易云、咪咕等平台（通过你导入并激活的音源）
- 关键词分页搜索：试听、加入试听列表、按音质下载
- 歌单：粘贴链接或 ID 解析；推荐歌单支持最热 / 最新
- **可同时激活多个音源**，同一平台失败时自动尝试其他已激活音源

### 试听与全屏播放

- 底栏播放器：播放 / 暂停、上一首 / 下一首、进度、音量
- **全屏播放**：大封面、实时滚动歌词、频谱可视化
- **桌面端**：宽屏完整控制、频谱与歌词沉浸布局
- **手机端**：自适应紧凑布局，全屏播放与搜索页均可使用
- 试听列表持久化；列表循环 / 单曲循环 / 随机；后台播放
- 深色 / 浅色主题

### 下载

- 下载任务队列，实时进度
- 音质选择；失败可重试原音质或降质下载
- 可选内嵌封面、歌词；可另存同名 `.lrc`
- 按专辑分子文件夹、自定义文件名格式

### 本地整理

- 扫描音乐库，批量编辑标签、封面与歌词
- 按文件名匹配网络元数据

### 飞牛使用

- 安装向导填写本机绝对路径即可使用
- 依赖应用中心 Node.js v22，请勿单独卸载
- 卸载时可选择保留或删除应用配置，不会删除你指定的音乐文件

## 安装说明

1. 应用中心安装本应用（商店渠道可直接安装或更新）
2. 若尚未安装 Node.js v22，系统会按依赖自动安装
3. 建议填写音乐库与下载目录的 NAS 绝对路径（文件管理 → 右键 → 详细信息 → 复制原始路径）
4. 安装完成后即可打开使用

手动安装包（按设备架构选择）：

- x86：`lemon-music-1.2.0-x86.fpk`
- ARM：`lemon-music-1.2.0-arm.fpk`
