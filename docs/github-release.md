# 柠檬音乐 v1.2.6

## 更新

### 账号与多用户

- 登录鉴权与流媒体 Token，多用户管理（创建 / 编辑 / 重置密码 / 删除）
- 邮箱绑定、验证与「忘记密码」（需配置 SMTP）
- 关于页展示服务健康与内存守护状态

### 下载

- **同名文件处理**：询问 / 跳过 / 覆盖；单曲即时确认，批量结束后汇总处理
- 本地已有文件时展示音质对比，再决定覆盖或跳过
- 加固网盘挂载目录下载：本机暂存后一次发布、识别 `名称(1)` 副本、入队去重，减轻夸克等网盘出现双文件问题

### 音乐库与移动端

- **网络歌单自动更新**（按间隔检查新增）+ 手动「更新歌单」
- **音乐库热更新**：下载完成 / 后台扫描 / 目录变化时增量刷新并提示
- 智能歌单本地曲目正确显示「本地」标；歌单网格桌面两行 / 全部歌单一行
- 有自定义歌单时，全部歌单页优先展示相关歌单
- 手机端隐藏歌单大封面；曲目操作收纳为「更多」菜单
- 音乐库歌曲列数可调（2 / 3 / 4）

### 播放

- 移除手机横屏播放模式；全屏标签编辑与试听列表层级优化
- 搜索 / 发现虚拟列表与缓存；标签匹配与本地播放稳定性提升

本版仍为原生独立应用（不依赖 Docker），依赖应用中心 Node.js v22。

## 安装包

- `lemon-music-1.2.6-x86.fpk`
- `lemon-music-1.2.6-arm.fpk`
