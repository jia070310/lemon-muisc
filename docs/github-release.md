# 柠檬音乐 v1.2.16

## 更新

### 全屏歌词

- 支持 **逐行 / 逐字** 切换；酷狗 KRC 真逐字高亮，无逐字时自动降级
- 手动滚动后空闲自动回到当前播放行；工具栏与歌词模式按钮随界面显隐，减少遮挡

### 关于页

- 展示本版更新说明；提供 GitHub / 镜像加速下载
- 按架构提供 x86 / ARM 安装包直链（请按 NAS CPU 手动选择，非自动识别）
- 说明：应用中心也可上传 FPK 手动安装

### 标签与下载

- 标签匹配可参考文件夹结构，仅补全缺失字段
- 按字段批量写入；合唱曲在每位歌手下可见，整理可取第一位歌手
- 同名不同格式下载并存，不误删已有文件
- 设置侧栏固定；独立「标签管理」页

本版仍为原生独立应用（不依赖 Docker），依赖应用中心 Node.js v22。

## 安装包

- x86：`lemon-music-1.2.16-x86.fpk`
- ARM：`lemon-music-1.2.16-arm.fpk`
