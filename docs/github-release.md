# 柠檬音乐 v1.2.17.21

## 更新内容

### 网络封面与试听稳定性

- 封面抓取增加总耗时上限，超时快速失败，不再长时间转圈
- 校验响应真实图片格式，HTML/JSON 错误页、空响应直接判失败
- 酷狗等防盗链平台先带 Referer 抓取，失败后自动去掉 Referer 兜底
- 网络试听代理补齐超时控制；上游返回非音频内容时不再当作成功
- 取链缓存遇到失效链接自动清除并重新取链，减少「点了没反应」
- 本地试听 Range 解析更完整（前缀 / 开区间 / 后缀 / 多段 / 越界），文件缺失返回 404

### 自动备份

- 音源、歌单、收藏、播客订阅有新增或变更即自动备份，不再依赖是否检测到新版本
- 播放历史变化不触发备份，避免频繁写盘
- 自动备份最多保留 20 份，超出自动删除最早的文件
- 备份导入支持新格式，可同时恢复音源与播客订阅

### 数据导出

- 设置页新增「导出全部音源」，播客页新增「导出订阅」，导出文件可直接用于备份导入

## 安装 / 更新

- x86：`lemon-music-1.2.17.21-x86.fpk`
- ARM：`lemon-music-1.2.17.21-arm.fpk`
