# 柠檬音乐 v1.2.14.3

## 更新

> **鸣谢**：[(@theroad)](https://github.com/theroad) · [PR #18](https://github.com/jia070310/lemon-muisc/pull/18)（歌手浏览 / 文件管理 / 播放自动匹配；本版未合入漫游歌单）

### 文件管理

- 标签编辑 / 去重 / 整理统一入口（默认标签编辑；`/tag` 跳转）
- 点击目录递归加载子目录音频
- 整理路径：`专辑艺术家 / 专辑 / 文件`；多歌手 →「群星 (Various Artists)」

### 音乐库

- 歌手列表与详情
- 多歌手曲目归入「群星」
- 搜索结果独立页 + 分页
- 可选外部目录监测（增量扫描）

### 播放 / 登录

- 播放自动匹配（标签缺失时联网补全并保存）
- 保持登录 30 天：Cookie 持久化，改善飞牛手机端登录易丢

本版仍为原生独立应用（不依赖 Docker），依赖应用中心 Node.js v22。
