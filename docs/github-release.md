# 柠檬音乐 v1.2.5

## 更新

### 音乐库

- 新增「音乐库」：扫描本地目录，浏览歌曲、专辑、歌单与流派
- 智能歌单（最新添加、最近播放、收藏）与自定义歌单；封面支持歌曲图或渐变卡片
- 扫描进度与标签读取状态提示；刷新后缓存加速加载
- 专辑「更多」跳转专辑列表页；歌单卡片名称过长自动省略

### 播放与全屏

- 全屏播放器横屏布局优化；内嵌歌词显示
- 切歌时复用已缓冲音频，减少重复加载；修复歌词偶发错乱
- 抑制浏览器「play 被 pause 打断」的无害报错

### 搜索与交互

- 多处搜索框支持一键清空；下拉菜单不再被底部栏遮挡
- 搜索页支持专辑搜索；移动端列表支持全选
- 下载重试或切换音质时自动清理未完成/重复文件

本版仍为原生独立应用（不依赖 Docker），依赖应用中心 Node.js v22。

## 安装包

- `lemon-music-1.2.5-x86.fpk`
- `lemon-music-1.2.5-arm.fpk`
