# 柠檬音乐 v1.2.7

## 更新

### 多用户数据隔离

- 歌单 / 收藏 / 最近播放按账号分开；本地缓存随登录切换
- 下载：共享默认路径 + 可选个人路径（默认 `{共享路径}/{用户名}/`）

### 音源

- 启用 / 停用按用户独立；普通用户可操作，导入 / 删除仍仅管理员
- 兼容 CeruMusic / 澜音原生音源，与落雪脚本并存

### 试听片段

- 播放时提示疑似预览源
- 下载前探测时长，短片段跳过并换源重试

### 其它

- 网络歌单更新时新增曲目插到最前

本版仍为原生独立应用（不依赖 Docker），依赖应用中心 Node.js v22。

## 安装包

- `lemon-music-1.2.7-x86.fpk`
- `lemon-music-1.2.7-arm.fpk`
