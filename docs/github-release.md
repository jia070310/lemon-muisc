# 柠檬音乐 v1.2.15.10

## 更新

### 发现页 · 酷我排行榜

- 修复排行榜详情空白：榜单请求改用正确的 `sourceid`，主接口失败时回退 kbang
- 修复封面缺失：对无图曲目补拉 musicInfo 封面
- 修复时长显示异常：kbang 列表使用 `song_duration`

### 界面

- 音乐库右上角去掉「情绪地图」按钮（侧栏 / 手机底栏仍可进入）

本版仍为原生独立应用（不依赖 Docker），依赖应用中心 Node.js v22。

## 安装包

- `lemon-music-1.2.15.10-x86.fpk`
- `lemon-music-1.2.15.10-arm.fpk`
