# 柠檬音乐 v1.2.3

## 更新

- **橙色主题**：统一柠檬橙配色与按钮光晕，音量条、播放器控件同步适配
- **多风格配色**：设置 → 风格样式，支持 8 种预设配色 + 自定义主色
- **批量下载音质**：菜单显示所有选中歌曲的音质并集；不支持所选音质的歌曲会弹出确认，可逐首或统一选择后再下载
- **频谱稳定性**：修复最小化恢复、自动切歌后频谱不跳动的问题
- **播放链接缓存**：重复试听同一首歌不再每次重新拉取 URL
- **酷狗歌单加速**：首屏快速加载 + 后台并行拉取剩余歌曲
- **酷狗搜索增强**：多接口回退，减少「暂无搜索结果」
- **歌词修复**：修复酷狗/酷我歌词换行导致不显示的问题
- **下载音质菜单**：底部歌曲下载时菜单不再被播放条遮挡，靠近底部自动向上弹出
- **手机端全选**：搜索/发现列表工具栏新增批量全选勾选框
- **标签编辑提示**：优化保存说明，明确需点右上角「保存全部修改」才会写入磁盘

本版仍为原生独立应用（不依赖 Docker），依赖应用中心 Node.js v22。

## 安装包

- `lemon-music-1.2.3-x86.fpk`
- `lemon-music-1.2.3-arm.fpk`
