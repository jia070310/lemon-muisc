# 柠檬音乐 v1.2.13

## 更新

### 音乐库 · 歌手

- 侧边栏「音乐库」下方新增「歌手」；音乐库首页也有歌手入口
- 歌手列表（头像 + 曲目 / 专辑数）分页展示，歌手再多也不卡
- 点歌手进入详情：全部歌曲、播放全部 / 随机 / 加入列表 / 收藏 / 歌单 / 分页

### 文件管理（下载下方新入口）

- **查重**：按（文件名解析的）歌名 + 歌手分组，同组至少保留一份；可复制路径、勾选批量删除，重复文件物理删除
- **整理**：参考标签编辑器交互——左侧目录树逐层浏览，点击文件夹右侧列出本层音频；勾选文件跨文件夹累计，点「整理选中」按歌手迁移到目标目录（同名自动加序号，跨盘自动复制 + 删除）
- 整理后音乐库自动刷新：数据不重复、歌手列表不丢失

### 播放

- 设置 → 音源管理新增「**播放自动匹配**」开关：播放本地音乐时若标签缺失（无专辑 / 封面 / 歌词）自动联网匹配并保存
- 歌单区「最新添加」前新增「**随机播放**」入口：随机抽 10 首放入「漫游歌单」立即播放；漫游 / 随机歌单快播完（剩余 ≤ 3）自动再补 10 首，已播放完成的自动从歌单清除

### WAV / APE 格式完善

- **标签编辑**：支持读写 WAV（RIFF INFO + ID3）、APE（APEv2），含封面与歌词保存
- **下载内嵌**：WAV / APE 也可写入封面、歌词
- **播放**：WAV 浏览器直接播放；APE 需本机安装 **ffmpeg**（自动转码为 WAV 后播放）

### 修复

- 整理迁移成功后不再误报「请求错误」
- 修复整理后数据重复（旧记录与新记录并存）
- 修复去重删除幽灵记录时报「路径不在允许的音乐库 / 下载目录内」

本版仍为原生独立应用（不依赖 Docker），依赖应用中心 Node.js v22。
