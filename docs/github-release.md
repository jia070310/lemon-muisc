# 柠檬音乐 v1.2.0

飞牛端重写为**独立原生应用**，不再依赖 Docker。安装包约 0.5 MB，运行时使用应用中心 **Node.js v22**。

## 变更

- 移除 Docker：避免开机「docker服务不可用」导致自动启用失败
- 原生进程，支持 IPv4 / IPv6
- 本机绝对路径管理音乐库与下载目录
- 支持同时激活多个音源
- 应用中心显示名：柠檬音乐（浏览器标题仍为柠檬音乐下载）

## 功能

多平台搜索、歌单发现、在线试听、全屏播放（桌面 / 手机）、频谱与滚动歌词、批量下载、本地标签编辑。

## 安装包

- `lemon-music-1.2.0-x86.fpk`
- `lemon-music-1.2.0-arm.fpk`
