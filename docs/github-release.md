# 柠檬音乐 v1.2.4

## 更新

- **下载管理增强**：关闭页面或重启后中断的任务自动标记为已暂停，可点「继续」恢复；新增「全部继续」「全部暂停」与批量操作
- **搜索/发现**：输入框按回车即可搜索或确认歌单
- **进度条/音量条**：悬停与按下时圆点显示当前配色风格的光晕，松开后恢复
- **标签编辑**：优化保存提示，明确需点「保存到文件」才会写入磁盘

本版仍为原生独立应用（不依赖 Docker），依赖应用中心 Node.js v22。

## 安装包

- `lemon-music-1.2.4-x86.fpk`
- `lemon-music-1.2.4-arm.fpk`
