# 柠檬音乐 v1.2.17.22

## 更新内容

### 应用内一键更新

- 关于页检测到新版本后，右上角「检测更新」自动变为「立即更新」
- 点击「立即更新」弹窗展示本次更新内容，底部提供「关闭」与「立即更新」
- 更新时自动识别当前系统架构（x86 / ARM）选择安装包，优先测速加速节点下载
- 下载完成后调用飞牛应用中心在后台覆盖安装并自动重启，无需手动导入安装包

### 音质升级

- 升级确认弹窗新增「是否保留原文件」选择
- 选择保留：原文件移动到下载目录下的 `lemon-originals`，按原目录结构归档
- 选择不保留：下载完成后直接覆盖原文件
- 归档目录不会被音乐库扫描，避免重复曲目

### 推荐歌单

- 推荐逻辑改为综合加权：试听时长权重最高，叠加收藏、加入歌单、播放次数与近期播放
- 新增试听时长统计，切歌或播完时补记实际收听时长
- 偏好候选按加权得分优先选取，再结合每日种子洗牌，兼顾口味与新鲜度

### 其他

- 音源删除增加二次确认，避免误删
- 关于页更新说明改为弹窗阅读，长文可滚动

## 安装 / 更新

- x86：`lemon-music-1.2.17.22-x86.fpk`
- ARM：`lemon-music-1.2.17.22-arm.fpk`
