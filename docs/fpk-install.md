# 飞牛 FPK 安装说明（v1.2.2 原生独立应用）

本应用为飞牛**原生进程**，**不依赖 Docker**，不拉取镜像。安装包约 0.5 MB，运行时使用应用中心 **Node.js v22**（`install_dep_apps=nodejs_v22`，未安装时随本应用安装）。

应用中心显示名：**柠檬音乐**。浏览器标题仍为「柠檬音乐下载」。默认端口 **7983**。

## 注意事项

1. 目录请填**本机绝对路径**：文件管理 → 右键文件夹 → 详细信息 → **复制原始路径**。
2. 安装时填好路径即可直接使用。若留空，可到应用设置 → **访问权限** 补充。
3. 依赖应用中心 **Node.js v22**。请勿单独卸载，否则应用无法启动。
4. 请仅用于管理你**个人已合法授权**的音乐资源。
5. **卸载**时可选择保留或删除应用配置；不会删除你指定的音乐库 / 下载文件夹中的音频。

## 安装流程

1. 应用中心安装对应架构 FPK：
   - x86：`lemon-music-1.2.2-x86.fpk`
   - ARM：`lemon-music-1.2.2-arm.fpk`
2. 阅读安装说明与注意事项
3. 填写音乐库、下载目录（建议填写）
4. 完成后即可在应用中心打开使用

## 数据目录

| 设置项 | 说明 |
|--------|------|
| 音乐库 | NAS 绝对路径，例如 `/vol1/1000/Music` |
| 下载目录 | NAS 绝对路径；可与音乐库相同 |
| 配置目录 | 自动使用应用数据目录 |

同一物理目录在设置里只会保留一条，无需再使用旧版容器路径 `/music`、`/downloads`。

## 卸载

| 选项 | 行为 |
|------|------|
| **保留应用数据（默认）** | 停止进程；保留配置、音源脚本、任务记录 |
| **删除应用数据** | 同时清除应用配置 |

不会删除你指定的音乐库、下载目录里的音频文件。

## 本机打包

```powershell
npm run fpk:build
```

输出：`fpk/lemon-music-1.2.2-x86.fpk` 与 `fpk/lemon-music-1.2.2-arm.fpk`（不要提交到 git）。
