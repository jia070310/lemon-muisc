大家好，柠檬音乐（飞牛应用中心显示名）发布 v1.2.15。

这一版的主打是「情绪地图」：把本地音乐按悲伤↔开心、慢↔快铺在一张图上，点封面就能按心情连播；底栏用心形 / 碎心告诉它「再来点相近的」或「跳过这类」。

同时继续整合社区贡献的音乐库能力，并修了本地播放假缓冲、下载目录套娃等问题。

特别鸣谢社区 @theroad：通过 GitHub PR #18 提供了歌手浏览、文件管理、播放自动匹配等能力（合入时未包含「漫游歌单」），让本地库好用很多。

应用仍为原生 FPK，不依赖 Docker，运行依赖应用中心 Node.js v22。

GitHub Release：https://github.com/jia070310/lemon-muisc/releases/tag/v1.2.15
仓库地址：https://github.com/jia070310/lemon-muisc

---

【本版亮点】

1. 情绪地图：分析本地曲库后，在坐标图上看封面点；滚轮 / 双指缩放，Shift 拖动画布
2. 播放心情：点封面进入独立「心情试听」队列，与普通试听列表互不影响
3. 心情反馈：底栏红心 = 喜欢这类心情（多播相近）；碎心 = 不喜欢（跳过并切下一首）。收藏改用星标，避免和心情反馈混淆
4. 手机底栏也可一键进「情绪」；侧栏图标换成红心心跳样式
5. 修：本地曲「暂停键亮着但 00:00 不走」的假播放；下载按专辑分组时同名文件夹一层层套娃
6. 延续：歌手浏览、文件管理（标签 / 去重 / 整理）、播放自动匹配、保持登录 30 天

【怎么用情绪地图】

1. 打开侧栏或手机底栏「情绪」/「情绪地图」
2. 点「开始分析」或「继续分析」，等本地曲扫描完
3. 点某张封面 →「播放心情」
4. 听的时候用心形 / 碎心调教下一首偏好；不喜欢可随时「退出心情试听」

提示：下载目录请设在分组根目录（例如 download），不要选进已经生成的专辑子文件夹，否则以前容易套娃；本版已做防套处理。

【安装 / 更新】

1. 到 GitHub Release 下载对应架构：
   - lemon-music-1.2.15-x86.fpk
   - lemon-music-1.2.15-arm.fpk
2. 飞牛应用中心 → 手动安装 / 更新 FPK
3. 依赖应用中心 Node.js v22（未装会随应用一并安装）
4. 首次或权限变更时，在访问权限里确认音乐库 / 下载目录

---

【给新人的一句话】

先在「发现」或「搜索」找歌下载到 NAS；用「文件管理 → 整理」按歌手 / 专辑归好类；想换心情时打开「情绪地图」，让本地库按感觉连播。

请仅用于个人已合法授权的音乐资源管理，遵守当地法律与各平台服务条款。
