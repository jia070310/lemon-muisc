大家好，柠檬音乐（飞牛应用中心显示名）发布 v1.2.13。

这一版围绕「本地音乐库」做了几件大事：新增歌手浏览，新增文件管理（查重 + 整理），播放时能自动匹配并保存缺失的标签。

应用仍为原生 FPK，不依赖 Docker，运行依赖应用中心 Node.js v22。

GitHub Release：https://github.com/jia070310/lemon-muisc/releases/tag/v1.2.13
仓库地址：https://github.com/jia070310/lemon-muisc

---

【本版亮点】

1. 音乐库新增「歌手」入口：歌手列表（头像 + 曲目 / 专辑数）分页展示，点进去播放全部 / 随机 / 加入列表 / 收藏 / 歌单
2. 新增「文件管理」（下载下方）：查重可按文件名解析的歌名 / 歌手分组、批量删除重复文件；整理参考标签编辑器交互，左侧目录树、右侧勾选文件，点「整理选中」按歌手迁移到目标目录
3. 「播放自动匹配」开关（设置 → 音源管理）：播放本地音乐时若标签缺失（无专辑 / 封面 / 歌词），自动联网匹配并保存
5. 修复：整理成功后不再误报请求错误；整理后数据不重复、歌手列表不丢失；去重删除幽灵记录不再报「路径不在允许目录内」

---

【界面预览】

一、音乐库 · 歌手

左侧菜单「歌手」进入歌手列表，封面圆头像 + 名称 + 曲目 / 专辑数，分页浏览不卡顿；点歌手看全部歌曲。

【配图：library-artists-v1.2.13.png】

二、文件管理 · 整理

左侧目录树逐层浏览，点文件夹右侧列出本层音频；勾选文件（可跨文件夹累计）后点「整理选中」，按歌手迁移到目标目录，同名自动加序号，跨盘自动复制 + 删除。

【配图：file-manager-organize-v1.2.13.png】

【安装 / 更新】

1. 到 GitHub Release 下载对应架构：
   - lemon-music-1.2.13.9-x86.fpk
   - lemon-music-1.2.13.9-arm.fpk
2. 飞牛应用中心 → 手动安装 / 更新 FPK
3. 依赖应用中心 Node.js v22（未装会随应用一并安装）
4. 首次或权限变更时，在访问权限里确认音乐库 / 下载目录

---

【给新人的一句话】

先在「发现」或「搜索」找歌试听，满意了点下载落到 NAS；再用「文件管理 → 整理」把歌按歌手归好类，播放时开着「播放自动匹配」让标签自动补全。

请仅用于个人已合法授权的音乐资源管理，遵守当地法律与各平台服务条款。
