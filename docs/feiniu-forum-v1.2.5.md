# 【柠檬音乐 v1.2.5 更新】本地音乐库上线 · 下载管理增强 · 标签批量整理

> **发帖说明**：正文可直接复制到飞牛社区。配图请上传 `docs/screenshots/` 目录下 4 张截图（文件名见各图说明）。

大家好，**柠檬音乐**（飞牛应用中心显示名）发布 **v1.2.5**。

这一版最大的变化是：**新增「音乐库」**，可以把 NAS 里已有的音乐扫进来统一管理；同时完善了下载列表操作、播放体验与标签整理流程。应用仍为**原生 FPK**，不依赖 Docker，安装包约 **0.6 MB**，运行依赖应用中心 **Node.js v22**。

**GitHub Release**：https://github.com/jia070310/lemon-muisc/releases/tag/v1.2.5  
**仓库地址**：https://github.com/jia070310/lemon-muisc

---

## 界面预览

### 1. 音乐库（本版重点）

扫描本地音乐目录后，可浏览**歌单、音乐风格、专辑**与歌曲列表。内置智能歌单「最新添加」「最近播放」「收藏」，也支持创建自定义歌单；顶部可一键「刷新库」「创建歌单」，扫描进度与歌曲数量会实时显示。

![音乐库](screenshots/library-v1.2.5.png)

---

### 2. 下载管理

任务列表支持刷新、全部继续/暂停、批量操作、清除已完成等。单条任务可试听；**「移出」**仅从列表移除（保留文件），**「删文件」**悬停变红后才会删除磁盘文件，避免误触。

![下载管理](screenshots/download-v1.2.5.png)

---

### 3. 下载分组

在「设置 → 下载设置」中可按**歌手、专辑或歌手/专辑两级目录**自动创建子文件夹，方便整理大批量下载。

![下载分组](screenshots/download-group-v1.2.5.png)

---

### 4. 标签编辑

扫描音乐库目录，批量查看缺失封面/歌词的文件；支持按文件名过滤、全选、匹配缺失元数据，单文件可编辑标题/歌手/专辑并保存到文件。

![标签编辑](screenshots/tag-editor-v1.2.5.png)

## 详细更新说明

### 音乐库（新功能）

- 扫描「设置 → 文件路径」中的音乐库目录（支持多路径）
- 智能歌单：**最新添加**、**最近播放**、**收藏**
- 自定义歌单：创建、重命名、挑选歌曲加入
- 歌单封面：系统歌单为渐变卡片，自定义歌单可用歌曲封面或上传图片
- 按 **音乐风格**、**专辑** 分类浏览；专辑列表独立页面
- 本地歌曲试听、收藏、加入试听列表
- 内嵌封面按需加载；修复部分 ID3 乱码与专辑名显示

### 下载与路径

- 音乐库路径 `music.paths` 与下载保存路径 `download.savePath` **分开配置**
- 下载列表：**移出**（仅移出列表）/ **删文件**（删除磁盘文件）
- 下载分组：不分组 / 按歌手 / 按专辑 / 按歌手+专辑两级目录

### 播放与全屏

- 手机横屏全屏播放器布局与频谱层级优化
- 全屏页显示内嵌歌词
- 最近试听过的歌曲切回时复用音频缓冲，减少等待
- 修复切歌时歌词未刷新的问题

### 搜索与交互

- 搜索页支持按 **专辑** 检索并查看专辑详情
- 搜索、音乐库、标签编辑等输入框支持 **一键清空**
- 排序/筛选下拉菜单使用固定定位，不再被底栏遮挡
- 下载重试或换音质时自动清理残留临时文件

## 安装与更新

### 方式一：应用中心（推荐）

若商店已上架 v1.2.5，在应用中心直接更新即可。

### 方式二：手动安装 FPK

从 GitHub Release 下载对应架构安装包：

| 架构 | 文件名 |
|------|--------|
| x86 | `lemon-music-1.2.5-x86.fpk` |
| ARM | `lemon-music-1.2.5-arm.fpk` |

应用中心 → **手动安装** → 选择 FPK 文件。

### 首次使用提示

1. 安装时会提示填写**音乐库目录**和**下载保存目录**（建议使用 NAS 绝对路径）
2. 若未安装 Node.js v22，会随应用一并安装
3. 默认访问端口：**7983**
4. 卸载时可选择保留或删除应用配置，**不会删除**你指定的音乐库/下载目录中的音频文件
