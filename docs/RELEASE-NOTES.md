# 柠檬音乐 v1.2.17.25

## 更新内容

### 下载 · 同名检测
- 音乐库索引新增 `file_base` 全路径检索键，下载同名检测不再依赖整盘扫描
- 兼容 `06. 歌手 - 歌名` 与 `歌名 - 歌手` 等命名差异；支持多候选键 + 歌名/歌手身份匹配
- 启动后后台分批回填 / 纠正旧键，避免阻塞服务

### 曲库扫描稳定性
- 合入大曲库相关修复（含 #59 / #60 / #61）：目录指纹、异步同步串行化、扫描路径等补丁落地源码

### 播放 · 可视化
- 桌面端开启转码（smooth）时不再误关频谱可视化
- 仅移动端音频环境继续避开 Web Audio 直通

### 播客
- 「最近更新」支持横向滚动浏览
- 修复滚动后卡片点击被指针捕获吞掉的问题
- 播放历史弹层在手机端恢复居中展示

### 音源探测
- 探测项悬停提示改为更完整的说明文案

## 安装 / 更新

- x86：`lemon-music-1.2.17.25-x86.fpk`
- ARM：`lemon-music-1.2.17.25-arm.fpk`
