# 柠檬音乐 v1.2.14.3

## 更新内容

> **鸣谢**：[(@theroad)](https://github.com/theroad) 在 [PR #18](https://github.com/jia070310/lemon-muisc/pull/18) 中贡献歌手浏览、文件管理、播放自动匹配等能力（本版合入时未包含「漫游歌单」）。

### 文件管理

- **统一入口**：标签编辑 / 去重 / 整理合并为「文件管理」（默认打开标签编辑；`/tag` 自动跳转）
- **目录加载**：点击目录递归加载全部子目录音频（可用「仅当前层」）
- **整理规则**：`目标目录 / 专辑艺术家 / 专辑 / 文件`（无专辑艺术家则用歌手）
- **多歌手**：整理与下载分组将多歌手曲目归档到「群星 (Various Artists)」

### 音乐库

- **歌手**：列表与详情（分页、播放全部 / 随机 / 收藏 / 歌单等）
- **多歌手归组**：歌手浏览中多歌手曲目归入「群星 (Various Artists)」
- **搜索结果页**：独立 `/library/search`，按歌曲 / 专辑 / 歌手 / 歌单展示，并固定每页数量分页
- **外部监测**：可设置间隔增量扫描，进入音乐库时同步热更新

### 播放

- **播放自动匹配**：设置 → 音源管理；本地曲目标签缺失时自动联网匹配并保存

### 登录

- **保持登录（30 天）**：登录会话写入 HttpOnly Cookie，改善飞牛手机端 WebView 清掉 localStorage 后需反复登录的问题

### 其它

- 音乐库首页查重入口移除（改用文件管理 → 去重）
- 侧栏不再单独放「歌手 / 标签编辑」入口，能力保留在音乐库与文件管理内

本版仍为原生独立应用（不依赖 Docker），依赖应用中心 Node.js v22。

## 安装 / 更新

- x86：`lemon-music-1.2.14.3-x86.fpk`
- ARM：`lemon-music-1.2.14.3-arm.fpk`

# 柠檬音乐 v1.2.13

## 更新内容

### v1.2.13.9 · 音乐库歌手 / 文件整理 / 播放自动匹配

#### 音乐库 · 歌手

- 侧边栏「音乐库」下方新增「歌手」；音乐库首页也有歌手入口
- 歌手列表（头像 + 曲目 / 专辑数）分页展示，歌手再多也不卡
- 点歌手进入歌手详情：全部歌曲、播放全部 / 随机 / 加入列表 / 收藏 / 歌单 / 分页

#### 文件管理（下载下方新入口）

- **查重**：按（文件名解析的）歌名 + 歌手分组，同组至少保留一份；可复制路径、勾选批量删除，重复文件物理删除
- **整理**：参考标签编辑器交互——左侧目录树逐层浏览，点击文件夹在右侧列出本层音频；勾选文件可跨文件夹累计，点「整理选中」按歌手迁移到目标目录（同名自动加序号，跨盘自动复制 + 删除）
- 整理后音乐库自动刷新：数据不重复、歌手列表不丢失

#### 播放

- 设置 → 音源管理新增「**播放自动匹配**」开关：开启后播放本地音乐时，若标签缺失（无专辑 / 封面 / 歌词）会自动联网匹配并保存

#### 修复

- 整理迁移成功后不再误报「请求错误」
- 修复整理后数据重复（旧记录与新记录并存）
- 修复去重删除幽灵记录时报「路径不在允许的音乐库 / 下载目录内」

### v1.2.13.0 · WAV / APE

- 标签编辑支持保存 WAV（RIFF INFO + ID3）、APE（APEv2），含封面与歌词
- 下载内嵌封面 / 歌词支持 WAV、APE
- WAV 可直接播放；APE 需本机 ffmpeg 转码为 WAV 后播放

本版仍为原生独立应用（不依赖 Docker），依赖应用中心 Node.js v22。
