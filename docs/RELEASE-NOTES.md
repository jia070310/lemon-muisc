# 柠檬音乐 v1.2.17.18

## 更新内容

### 飞牛 HTTPS 证书（#48）

- 启动时优先跟随飞牛「服务配置」当前启用的证书，不再被配置目录里旧的 `certName` 粘住
- 改域名证书后停用再启用即可切换；仅设置环境变量 `LEMON_SSL_CERT_NAME` 时才会锁死指定证书

### 打开速度

- 端口先监听，音源沙箱 / 元数据刷新改为后台加载，不再挡住「应用可打开」
- 发现预热、库监测、情绪分析、自动备份错开延后，用户打开后再慢慢跑
- 播放器设置合并为一次请求；音乐库先读本地快照，扫库延后后台

### 缓存目录

- 转码 / 封面 / 发现页 / 下载半成品等磁盘缓存统一到应用数据目录 `config/cache/`（飞牛约 `@appdata/lemon-music/config/cache/`）
- **不再**写入音乐库或下载目录；扫库会跳过缓存路径与 `.part` / `.partial` 半成品
- 旧版 `cover-cache`、`discover-feed-cache`、`download-staging` 及系统临时目录中的转码缓存会尽量自动迁移

### 下载 · 假无损说明

- **现象**：搜索菜单显示超清母带等大体积档（如约 200MB+），实际落盘只有普通 FLAC（约几十 MB）
- **原因**：菜单体积来自音源脚本声明的元数据；取链后若返回 MP3/M4A 等「假无损」，应用会拒绝保存并按策略换源或降档，最终可能落到可用的普通 FLAC
- **说明**：这不是体积显示算错，也不是把母带「压小」；要更高档请换能真正提供对应流的音源，或在下载策略里选「不降档」以便失败时明确提示

### 预告 · v2.0.0

- 下一阶段计划发布 **v2.0.0**，界面将有较大改版；本版本仍以稳定与体验优化为主，欢迎继续反馈
