# 柠檬音乐下载 Lemon Music v1.0.4

暂时兼容落雪音源 · 适配飞牛 NAS 的音乐搜索 / 试听 / 下载 / 标签工具

---

## 一、前言

自己做了个音乐小工具，适配飞牛 NAS（支持 FPK / Docker），方便在 NAS 上搜歌、试听、下载，顺带整理本地音乐标签和封面。

仅供个人学习、整理本地曲库使用，请遵守各平台规定与版权要求，勿用于商业用途。

---

## 二、功能介绍

1. **多平台搜索**：酷我 / 酷狗 / QQ音乐 / 网易云 / 咪咕
2. **在线试听**：试听列表、播放控制、队列持久化
3. **标签页试听**：本地文件试听，支持「试听全部」
4. **一键下载**：按设置内嵌封面/歌词，可选生成 `.lrc`
5. **自定义音源**：兼容落雪音乐 `.js` 音源，本地/在线导入
6. **标签编辑**：批量改标题、歌手、专辑，自动匹配封面/歌词
7. **主题切换**：浅色 / 深色模式

## 五、安装 / 升级（FPK）

> **不要用应用卡片上的「更新」**，请用手动安装。

1. SSH 拉镜像（推荐）：

```bash
docker pull ghcr.1ms.run/jia070310/lemon-muisc:latest
docker tag ghcr.1ms.run/jia070310/lemon-muisc:latest lemon-music:latest
```

2. 应用中心 → **手动安装** → 选择 `lemon-music-1.0.4.fpk`
3. 向导选 **「跳过拉取」**
4. 装完后 → 应用设置 → 访问权限（音乐库 + 下载目录）→ 保存
5. **停用 → 启用**，访问 `http://NAS_IP:7983`

## 六、常见问题

**Q：升级报 Request failed？**  
用手动安装 FPK，不要点卡片「更新」。

**Q：拉了好几次镜像还是旧版？**  
执行 `docker tag ghcr.1ms.run/jia070310/lemon-muisc:latest lemon-music:latest`，再停用/启用。

**Q：挂载还是 @appdata？**  
访问权限添加真实文件夹，保存后停用再启用。
