## 二、四大核心功能（重点）

### 1. 搜索 · 试听 · 下载

- 支持 **酷我 / 酷狗 / QQ 音乐 / 网易云 / 咪咕** 五平台关键词搜索
- 搜索结果可 **试听**、加入播放队列、**按音质下载**（128k / 320k / flac 等，取决于音源）
- 下载任务队列：并发下载、自定义文件名、跳过已存在、按专辑分子目录
- 可选 **内嵌封面 / 歌词** 到 MP3，或单独保存 `.lrc`
- 兼容 **落雪（LX Music）自定义音源**，VIP 音源脚本可直接使用

### 2. 发现 · 歌单（v1.0.8 新增）

侧栏新增 **「发现」** 页，专门处理歌单：

- 粘贴各平台 **歌单链接或 ID**，一键解析歌单内全部歌曲
- 空输入时展示 **推荐歌单** 网格，支持 **最热 / 最新** 排序
- 切换平台 Tab（酷我 / 酷狗 / QQ / 网易 / 咪咕）自动切换推荐与解析规则
- 歌单歌曲支持：**单曲试听**、加入队列、**整专加入列表**、**按音质下载**
- 布局与搜索页一致，上手零成本

> 歌单试听已对齐落雪 musicInfo 字段，VIP 音源在歌单场景下也可正常取链；远程音频经服务端代理，避免浏览器跨域导致无法播放。

### 3. 标签 · 批量编辑

**标签编辑** 页面向 NAS 本地曲库：

- 扫描指定目录，列出全部音频文件
- **单文件 / 多选批量** 编辑：歌名、歌手、专辑、年份、流派、注释
- **批量写入** ID3 标签到磁盘（MP3 等）
- **批量匹配元数据**：按文件名自动识别并填充标签
- **网络匹配封面 / 歌词**：选中多首后可批量拉取并写入
- 编辑过程中可直接 **试听** 本地文件

适合整理下载回来的零散 MP3、统一补全封面歌词。

### 4. 在线试听

- 底栏播放器：播放 / 暂停、进度、音量、封面展示
- 试听队列：上一首 / 下一首、列表 / 循环 / 单曲 / 随机
- 歌词滚动显示（有歌词时）
- 队列与播放状态 **本地持久化**，刷新页面可恢复

## 五、升级步骤（请务必按这个来）

> **不要点应用卡片上的「更新」**，请用 **应用中心 → 手动安装** 覆盖。

### 推荐流程

1. 下载最新 `lemon-music-1.0.8.fpk`
2. 应用中心 → **手动安装** → 选该 FPK
3. 向导：
   - **第一次 / 没有镜像**：选「1ms 加速」或默认在线拉取，等进度到 100%
   - **Docker 里已有 lemon 相关镜像**：选「**跳过拉取**」更快
4. 装完 → 应用设置 → **访问权限**（音乐库 + 下载目录）→ 保存
5. 点 **启用**，浏览器打开 `http://NAS_IP:7983`
6. **设置 → 音源管理** 导入并激活落雪音源脚本

### 网络不好时（SSH 预拉）

```bash
docker pull ghcr.1ms.run/jia070310/lemon-muisc:1.0.8
docker tag ghcr.1ms.run/jia070310/lemon-muisc:1.0.8 lemon-music:latest
```

然后再手动安装 FPK，向导选「跳过拉取」。

## 七、常见问题

**Q：装到一半提示 Docker Hub / registry-1.docker.io 超时？**  
请换 **最新 1.0.8 FPK**。旧包可能误拉 Docker Hub 短名。

**Q：进度条长时间停在 55% / 80%？**  
到 Docker「本地镜像」看是否已有 `ghcr.1ms.run/.../lemon-muisc`；有的话取消后重装并选「跳过拉取」。

**Q：歌单里有的歌试听失败？**  
确认音源已激活；部分歌曲受平台版权 / VIP 限制无法播放，换一首或换音质试试。

**Q：搜索能播、歌单不能播？**  
请确认已更新到 **1.0.8** 并拉新镜像，旧版歌单字段不完整。

**Q：升级失败 / Request failed？**  
一律用手动安装 FPK，不要点卡片「更新」。

**Q：挂载还是 @appdata？**  
访问权限重新选两个文件夹并保存 → 停用再启用。
