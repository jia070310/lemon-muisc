## 二、v1.0.7 / 1.0.6 更新摘要

### v1.0.7（音源故障隔离，重点）

- 音源运行时错误（如域名解析失败 `ENOTFOUND`）**不再导致 Node 进程退出、容器重启循环**
- 自动停用故障音源，Web 界面弹窗提示，可选「删除音源」或「删除并重新导入」
- **需更新 Docker 镜像**（应用代码变更，非仅 FPK 脚本）

### v1.0.6（安装 / 启用）

相对 1.0.4，安装体验变化最大，核心如下：

1. **安装卡住 / 假死**
   - 40%：解压阶段不再在 `install_init` 里长时间拉镜像
   - 55%：恢复飞牛 `docker-project` 系统进度（可看到 55→65→80）
   - 80%：镜像已在 Docker「本地镜像」里即可判定成功，不再死等
   - 脚本拉取与飞牛系统拉取并行时，避免互相抢 Docker 导致挂几十分钟

2. **误连 Docker Hub 超时**
   - 以前 compose 里若写成短名 `lemon-music`，飞牛会去拉 `registry-1.docker.io`，国内基本超时失败
   - 现已固定为完整地址：`ghcr.1ms.run/jia070310/lemon-muisc:latest`

3. **装完有镜像、没容器 / 启用报「docker不可用」**
   - 镜像确认就绪后会尝试软启动容器
   - 启用时优先用本地镜像；Docker 异常时给出更明确提示

4. **国内网络**
   - 安装向导可选加速源：1ms / 南大 nju / dockerproxy / DaoCloud
   - 本地已有镜像时可直接选「跳过拉取」

5. **其它**
   - 安装窗口可看到更真实的拉取进度文案
   - 拉取失败不再「假成功」装完却没镜像

> 说明：1.0.6 主要是 **FPK 安装脚本** 修复；**1.0.7 含应用本体更新**，升级后请拉 `ghcr.1ms.run/jia070310/lemon-muisc:1.0.7` 或 `latest`。

## 四、升级步骤（请务必按这个来）

> **不要点应用卡片上的「更新」**，请用 **应用中心 → 手动安装** 覆盖。

### 推荐流程

1. 下载最新 `lemon-music-1.0.7.fpk`
2. 应用中心 → **手动安装** → 选该 FPK
3. 向导：
   - **第一次 / 没有镜像**：选「1ms 加速」或默认在线拉取，等进度到 100%
   - **Docker 里已有 lemon 相关镜像**：选「**跳过拉取**」更快
4. 装完 → 应用设置 → **访问权限**（音乐库 + 下载目录）→ 保存
5. 点 **启用**，浏览器打开 `http://NAS_IP:7983`

### 网络不好时（SSH 预拉）

```bash
docker pull ghcr.1ms.run/jia070310/lemon-muisc:latest
docker tag ghcr.1ms.run/jia070310/lemon-muisc:latest lemon-music:latest
```

然后再手动安装 FPK，向导选「跳过拉取」。

## 五、常见问题（1.0.4 用户最常遇到）

**Q：装到一半提示 Docker Hub / registry-1.docker.io 超时？**  
旧包把短名当成 Docker Hub 拉了。请换 **最新 1.0.7 FPK**，不要再用会写 `lemon-music` 短名去让飞牛拉仓库的旧包。

**Q：进度条长时间停在 55% / 80%？**  
请确认装的是最新 1.0.7。可到 Docker「本地镜像」看是否已有 `ghcr.1ms.run/.../lemon-muisc` 或 `lemon-music`；有的话取消后重装并选「跳过拉取」，再启用。

**Q：安装显示完成，但没有容器 / 启用报 docker 不可用？**  
先到飞牛 Docker 确认服务正常；再到应用中心点启用。仍不行可 SSH：

```bash
docker images | grep -E 'lemon-music|lemon-muisc'
docker start lemon-music
# 若没有容器，可按访问权限里的目录手动 docker run，或重装最新 FPK
```

**Q：升级失败 / Request failed？**  
一律用手动安装 FPK，不要点卡片「更新」。

**Q：挂载还是 @appdata？**  
访问权限重新选两个文件夹并保存 → 停用再启用。
