# 【柠檬音乐 v1.2.6 更新】多用户登录 · 同名下载智能处理 · 音乐库与手机体验打磨

> **发帖说明**：正文可直接复制到飞牛社区。配图位置已用「【配图：…】」标出，请按说明自行截图后替换。

---

大家好，**柠檬音乐**（飞牛应用中心显示名）发布 **v1.2.6**。

相对网络仓库里的 **v1.2.5**，这一版重点在三块：

1. **多用户登录与权限**（家庭 NAS 共用更安心）
2. **下载遇同名文件可询问 / 跳过 / 覆盖**，并对比本地已有音质
3. **音乐库与手机端体验**持续打磨（标识修正、歌单布局、操作收纳；去掉手机横屏播放）

应用仍为**原生 FPK**，不依赖 Docker，安装包约 **0.8 MB**，运行依赖应用中心 **Node.js v22**。

**GitHub Release**：https://github.com/jia070310/lemon-muisc/releases/tag/v1.2.6  
**仓库地址**：https://github.com/jia070310/lemon-muisc

### 1. 登录 / 多用户（本版重点）

首次安装可创建管理员；设置中可管理用户、绑定邮箱，配置 SMTP 后支持验证邮箱与忘记密码。

### 2. 同名文件下载提示

下载目录已有同名歌曲时，可按设置「询问 / 跳过 / 覆盖」处理；询问模式下会对比本地音质与本次下载音质。批量下载结束后还会弹出冲突汇总。

【配图：同名文件询问弹窗；设置-同名文件处理】

### 3. 音乐库歌单（桌面）

首页歌单默认两行，「更多」展开；进入全部歌单页默认一行，有自定义/导入歌单时优先展示这些歌单（没有时才显示最近添加 / 收藏 / 最近播放）。本地曲在智能歌单中正确显示「本地」标。

【配图：音乐库首页歌单两行；全部歌单页一行 + 本地标识】

### 4. 手机端音乐库

歌单详情不再显示大封面卡片；歌曲行右侧操作收纳为「⋮」更多菜单，标题不再被按钮挤占。

## v1.2.6 相对 v1.2.5：新增与改动

| 类别 | v1.2.5 | v1.2.6 新增 / 改动 |
|------|--------|-------------------|
| **账号** | 无登录 | **登录鉴权**、多用户管理、邮箱验证 / 忘记密码（SMTP） |
| **下载同名** | 跳过已存在等基础选项 | **询问 / 跳过 / 覆盖**；音质对比；批量冲突汇总 |
| **本地/网络标** | 导入歌单可用 | 修复智能歌单（最近添加等）本地曲误标「网络」 |
| **歌单布局** | 卡片全部铺开 | 首页两行；全部歌单一行 + 优先自定义歌单 |
| **手机歌单** | 大封面 + 行内多按钮 | 隐藏大卡片；操作收纳为「更多」 |
| **风格样式** | 主题 / 配色 | 音乐库歌曲 **2 / 3 / 4 列** |
| **全屏播放** | 支持手机横屏播放 | **移除横屏播放**；标签编辑与试听列表层级优化 |
| **性能** | 库缓存等 | 搜索/发现虚拟列表与缓存、内存守护、本地播放更稳 |

> **v1.2.5 保留能力**（本版继续可用）：音乐库、复制网络歌单、下载继续/暂停、移出列表与删文件、标签编辑、多音源、频谱与全屏歌词等。

## 详细更新说明

### 账号与安全

- Web 访问需登录；试听流媒体使用独立鉴权，避免链接被随意访问
- 管理员可创建普通用户、重置密码、删除账号
- 可选配置 SMTP：验证邮箱、忘记密码找回
- 关于页可查看服务健康与内存守护状态

### 下载：同名文件

- 设置 → 下载设置 → **同名文件处理**：询问（默认）/ 跳过 / 覆盖
- 单曲：立即弹出确认（本地音质 vs 要下音质）
- 批量：队列结束后汇总，可全部跳过、全部覆盖或逐首处理

### 音乐库与歌单

- 「最近添加 / 收藏 / 最近播放」中本地文件正确显示 **本地**
- 桌面首页歌单预览 **两行**；全部歌单页预览 **一行**（可点「更多」）
- 有用户创建的歌单时，全部歌单页不刷智能三张卡；没有自定义歌单时才显示智能歌单
- 音乐库歌曲网格列数可在设置中选择

### 手机与全屏

- 歌单详情隐藏大封面，空间留给曲目列表
- 曲目操作（加入试听 / 歌单 / 收藏）收进「更多」
- 去掉全屏「横屏播放」按钮与相关逻辑，避免飞牛 WebView 假横屏不稳定
- 全屏下打开标签编辑、试听列表不再被角标挡住

### 其它

- 搜索 / 发现大列表更流畅；长时间运行有内存守护
- 标签匹配、文件名解析增强；临时网络错误不再轻易停用整个音源

## 安装与更新

### 方式一：应用中心（推荐）

若商店已上架 v1.2.6，在应用中心直接更新即可。

### 方式二：手动安装 FPK

从 GitHub Release 下载对应架构安装包：

| 架构 | 文件名 |
|------|--------|
| x86 | `lemon-music-1.2.6-x86.fpk` |
| ARM | `lemon-music-1.2.6-arm.fpk` |

应用中心 → **手动安装** → 选择 FPK 文件。

### 首次使用提示

1. 首次打开按提示创建**管理员账号**（可选配置邮件）
2. **设置 → 音源管理** 导入并激活落雪兼容音源
3. **设置 → 文件路径** 配置音乐库目录与下载目录
4. 默认端口：**7983**
5. 卸载不会删除你指定的音乐库 / 下载目录中的音频

## 主要功能一览（本版仍支持）

- **搜索 / 发现**：多平台检索、推荐歌单、试听、批量下载
- **音乐库**：本地扫描、智能歌单、自定义 / 导入网络歌单、专辑与风格浏览
- **下载**：队列进度、断点继续、音质降档、同名文件策略、分组保存
- **播放**：底栏播放器、频谱、全屏歌词、试听列表、后台播放
- **标签编辑**：批量扫描、网络匹配、写入文件
- **设置**：多音源、主题配色、路径、邮件、多用户（管理员）
